Mii Renderer

This is a tool to render a Mii into image form. It works for many types of Miis - ones created on the Wii, a QR Code, or even a Mii on WiiLink's Check Mii Out Channel! The output can be customized however you like. This works great to use as a profile picture!

Also see Mii Renderer (REAL) by Arian - Open-source renderer with Wii U/Switch/Miitomo styles, conversion, 3D export, and more.

Supports: Mii data Hex/Base64, Check Mii Out Channel code, cdn-mii ID
Supports byte sizes: Wii (74/76), 3DS/Wii U (92/96), Switch (48/68/88), Studio (46)
You may also drag-and-drop a QR code image or Mii data file
How to obtain a Mii ID from a Nintendo Account/Mii Studio 
Getting your Mii ID - Only if you're importing from Nintendo Account/studio.mii.nintendo.com.

Nintendo Account:
1. Go to https://accounts.nintendo.com/ and log into an account with a Mii.
2. Open any image of your Mii in a new tab.
    - Right click (or long hold touch on mobile) the circle with your Mii in it.
    - The Mii image is usually in User Info, or after opening the menu in the top right corner.

3. The URL should look somewhat like this if you grab the right one:
https://cdn-mii.accounts.nintendo.com/2.0.0/mii_images/a6eec3a6cf628d5d/c6e36c183112cd1be0eed159f5a49d0b.png?type=face ...

4. **The value you want is between "/miis/" and "/image/" in the URL.**
    - Mine would be "a6eec3a6cf628d5d".
    - Nothing else in that URL matters.

Mii Studio:
1. Open the Mii Studio/Nintendo Account Mii editor.
    - At https://accounts.nintendo.com/, hit "Edit" next to Profile.
    - There will be an "Edit Mii" button under your Mii. Click and you'll enter the website.
    - You should now see up to 6 characters with the text "Please select a Mii."
2. Edit the Mii you want

3. Copy the URL you are currently at. It should look like: https://studio.mii.nintendo.com/miis/a6eec3a6cf628d5d/edit?client_id=f2503ae55136cd57

4. **The value you want is between "/miis/" and "/edit?client_id=..." in the URL.**
    - Mine would be "a6eec3a6cf628d5d".
    - Nothing else in that URL matters.
